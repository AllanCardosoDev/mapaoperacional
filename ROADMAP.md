# Roadmap do Projeto

## ✅ Concluído (v1.0.0)

- [x] Mapa operacional com 62 municípios
- [x] Interface tática fiel ao quadro físico
- [x] Drag & Drop para ativos operacionais
- [x] Exportação de cenários em PNG
- [x] Salvar/carregar missões
- [x] Integração com Claude API
- [x] CI/CD completo com GitHub Actions
- [x] Testes automatizados
- [x] Documentação profissional
- [x] Docker support
- [x] TypeScript configuration
- [x] Security policy
- [x] CodeQL analysis
- [x] Dependabot configuration

## Em Desenvolvimento (v1.1.0)

- [ ] Migração completa para TypeScript
- [ ] Testes E2E com Playwright
- [ ] Modo offline com Service Workers
- [ ] Exportação para PDF
- [ ] Temas claro/escuro
- [ ] Internacionalização (pt-BR, en-US)

## Planejado (v2.0.0)

- [ ] Backend Node.js para persistência
- [ ] Autenticação de usuários (RBAC)
- [ ] WebSocket para atualizações em tempo real
- [ ] PWA completo
- [ ] Dashboard analytics
- [ ] API RESTful documentada com Swagger

## Futuro (v3.0.0)

- [ ] Multiplayer colaborativo
- [ ] IA preditiva para alocação de recursos
- [ ] Integração com sistemas externos (INPE, IBAMA)
- [ ] Mobile app nativo
- [ ] Realidade aumentada para visualização
- [ ] Machine learning para previsão de incidentes
