## Reportando uma Vulnerabilidade

A equipe do CBMAM leva segurança a sério. Se você descobrir uma vulnerabilidade de segurança, por favor nos ajude reportando-a de forma responsável.

**Por favor, NÃO crie uma issue pública no GitHub.**

### Processo de Reporte

1. Envie um e-mail para **seguranca@cbmam.am.gov.br** com o assunto "Security Vulnerability Report"
2. Inclua:
   - Descrição detalhada da vulnerabilidade
   - Passos para reproduzir o problema
   - Impacto potencial
   - Sugestão de correção (opcional)

### O Que Esperar

- **Confirmação de recebimento**: Dentro de 48 horas úteis
- **Atualização inicial**: Dentro de 5 dias úteis
- **Plano de correção**: Dentro de 10 dias úteis
- **Correção publicada**: Dependendo da severidade, tipicamente dentro de 30 dias

### Divulgação Responsável

Após a correção ser desenvolvida e testada, trabalharemos juntos para coordenar a divulgação pública. Agradecemos sua paciência durante o processo.

## Boas Práticas de Segurança

- Nunca commite credenciais, tokens ou chaves API
- Use variáveis de ambiente para dados sensíveis
- Mantenha dependências atualizadas
- Revise PRs de contribuidores externos cuidadosamente
- Use HTTPS em todas as comunicações externas
